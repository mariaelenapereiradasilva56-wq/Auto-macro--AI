# Changelog

## v0.2.0 - Windows XP Edition
- Replaced LevelInfo-only test buttons with a floating GD AI panel attached to root game scenes.
- Added a draggable GD bubble that opens and hides the panel.
- Added a Windows XP-inspired title bar, minimize and close controls.
- Added IA and PLAY interface test actions.
- Automatic level scanning, route solving and gameplay input are still not implemented.

## v0.1.0
- Initial Android64 project for GD 2.2081 / Geode 5.11.2.
- LevelInfoLayer IA and PLAY prototype controls.
- Frame-based press/release macro model.
