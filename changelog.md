# Changelog

## v0.4.0 - Macro Recorder / Player prototype
- Added REC and PLAY controls to the floating panel.
- Captures player 1 button press/release events with PlayLayer frame indices.
- Saves the last recording as CSV in the mod's Geode save directory.
- Replays recorded events through PlayerObject button methods.
- Added a first single-player playback loop. Device testing is required before relying on timing.
- Neural level analysis, autonomous route solving, multi-player recording, and death-learning are not implemented.

## v0.3.0 - Neural Macro Generator UI
- Added a macro creation progress display prototype.
- Progress remains at 0% until real analysis and generation stages exist.

## v0.2.0 - Windows XP Edition
- Added draggable floating GD bubble and Windows XP-inspired panel.
- Added IA and PLAY interface test actions.

## v0.1.0
- Initial Android64 project for GD 2.2081 / Geode 5.11.2.
- LevelInfoLayer IA and PLAY prototype controls.
- Frame-based press/release macro model.
